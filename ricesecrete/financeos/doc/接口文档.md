> 版本：2026-07-10

---

## 一、通用约定

### 1.1 请求头

| Header | 值 | 说明 |
|--------|-----|------|
| `Content-Type` | `application/json` | POST/PUT 请求体 |
| `Authorization` | `Bearer <token>` | 认证 Token（公开接口除外） |

### 1.2 响应格式

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | `200` 成功，其他为失败 |
| msg | string | 提示信息 |
| data | mixed | 响应数据 |

### 1.3 分页参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| page | int | 1 | 页码 |
| limit | int | 10 | 每页条数（最大 100） |

### 1.4 分页响应

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "total": 100,
    "items": []
  }
}
```

## 二、错误码

| code | 说明 |
|------|------|
| 200 | 成功 |
| 40101 | 未登录 / Token 缺失 |
| 40102 | Token 无效或已过期 |
| 40103 | refresh_token 无效 |
| 40301 | 无权限访问 |
| 40302 | IP 不在白名单 |
| 40401 | 资源不存在 |
| 42201 | 参数校验失败 |
| 42202 | 用户名或密码错误 |
| 42203 | 用户名已存在 |
| 42207 | 登录已锁定 |
| 42208 | 需要验证码 |
| 42209 | 验证码错误 |
| 50000 | 服务器内部错误 |
| 10001 | 会员 Token 过期/无效（H5 专用，需重新登录） |

---

## 三、认证说明

### 3.1 管理后台

- 登录：`POST /admin/login`
- 请求头：`Authorization: Bearer <token>`
- 成功 `code` 为 `200`

### 3.2 会员 H5

- 登录：`POST /api/login/doLogin`
- 请求头：`Authorization: Bearer <token>`（JWT 中 `guard` 必须为 `member`）
- 业务成功外层 `code` 为 `200`；Token 失效时 `code` 为 `10001`
- 广告**发起/超额匹配**接口需签名（见「签名机制」）；轮询结果接口仅需登录，不需签名
- 匹配轮询成功时，订单数据嵌套在 `data` 内（兼容参考项目 `code: 0` 格式），见 5.5 节

**时段数据结构：**

GET 响应每条 session 含 `level_type_list`（数组，便于前端多选）；保存时可用 `level_types` 或 `level_type_list`：

```json
{
  "sessions": [
    {
      "id": 1,
      "started_at": "09:00:00",
      "ended_at": "12:00:00",
      "level_types": ",1,2,",
      "level_type_list": [1, 2],
      "status": 1,
      "sort": 1
    }
  ]
}
```

`level_types` 存储格式：逗号包裹的类型 ID，如 `,1,2,3,4,` 表示四种类型均适用。

## 六、签名机制（广告匹配）

以下接口需要签名：

- `POST /api/finance_product/match`
- `POST /api/finance_product/overdue_match`

签名参数：`password`、`level_id`、`timestamp`、`type`（不含 `sign` 本身）。

算法（`ApiSignHelper::verify`）：

1. 移除 `sign` 字段，对其余参数按 key 升序排序
2. 拼接 `http_build_query($params) . $secret`
3. 计算 `md5`，与请求中的 `sign` 比对

`$secret` 来自 `sy_settings` 键 `api_sign_secret`（默认值见 `ApiSignHelper`）。
