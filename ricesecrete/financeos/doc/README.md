## 项目简介

广告刷单系统是一套面向广告库存撮合交易场景的全栈平台，包含：

- **管理后台**：运营配置、会员管理、订单审核、报表统计
- **H5 用户端**：广告位匹配交易、充值提现、团队推广、活动参与
- **后端 API**：Webman 高性能 PHP 框架，JWT 认证，RBAC 权限

### 技术栈概览

| 层级 | 技术 |
|------|------|
| 后端 | PHP 8.1+ / Webman ~2.2.3 / Eloquent ORM |
| 管理前端 | Vue 3 / Element Plus / Vite / Pinia / TypeScript |
| H5 前端 | Vue 3 / Vant / Vite |
| 数据库 | MySQL 8.0+ |
| 缓存/队列 | Redis 7.0+ |

### 默认访问地址

| 服务 | 地址 |
|------|------|
| 后端 API | `http://127.0.0.1:8787` |
| 管理后台 | `http://127.0.0.1:4000`（`frontend` 目录 `pnpm dev`） |
| H5 | `http://127.0.0.1:3000`（`web` 目录 `pnpm dev`） |

## 文档维护

- 新增业务模块时，同步更新 **业务功能文档** 与 **接口文档**
- 路由变更后执行 `php webman menu --fresh` 刷新权限，并更新接口文档
- 数据库表变更后执行 `php webman model` 同步结构，并更新开发文档中的表说明
